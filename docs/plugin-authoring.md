# Plugin authoring

See [plugin protocol](plugin-protocol.md) for the complete metadata, health, current, and refresh contracts. Use `check-now plugin create <id>` to generate the protocol v2 starting bundle.

Protocol v2 requests contain `protocol`, `id`, `mode`, `timestamp`, configuration, and optionally `prior`. Modes are `metadata`, `health`, `current`, and `refresh`. Metadata must advertise all three capabilities: `current`, `refresh`, and `health`. Health responses contain `protocol`, `id`, an RFC3339 `checked_at`, and structured checks with stable codes, `ok`/`warning`/`error` status, a short summary, and optional repair guidance. Health must stay offline and must not include environment values or secrets. Current and refresh return the result fields and statuses described in the protocol document.

For `update_available`, include versions and `argv` only when the installation manager is confidently known. Include an official `source_url` and explanation when a command cannot be safely determined. Logs belong on stderr; stdout contains exactly one JSON result.

Plugins are trusted local code. There is no remote installation mechanism, and `argv` is display-only. The canonical ID is the containing directory name and `plugin.sh` is the only executable entrypoint.

Built-in checkers must resolve targets from their documented official source. A failed or malformed release lookup is `unknown`, never `up_to_date`. Their health checks inspect local command availability and documented release/target overrides without printing override values. Node additionally uses `fnm list-remote` or `nvm ls-remote` when it can prove the current Node belongs to that manager; otherwise it falls back to the official Node distribution index without inventing an update command. Claude Code uses `claude --version` and the official `anthropics/claude-code` release feed, and emits `claude update` or the documented npm command only for proven native or npm installations. Codex uses the official `openai/codex` release feed and emits the official standalone installer command, npm command, or Homebrew command only when the corresponding installation layout is proven. Unknown ownership remains `unknown`.
