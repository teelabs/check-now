# Check Now Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a safe Go CLI that discovers executable update-checker plugins, caches validated results, and exposes shell-friendly reporting.

**Architecture:** A small `internal` host owns protocol validation, plugin execution, cache atomicity, stale policy, and locks. Built-in checkers are executable POSIX scripts discovered beside the host; local configured plugin directories use the same protocol.

**Tech Stack:** Go standard library, POSIX shell, JSON protocol, Go tests.

**Spec:** `docs/superpowers/specs/2026-10-26-check-now.md`

## Global Constraints

- Protocol version is `1`.
- Supported statuses are `not_installed`, `up_to_date`, `update_available`, and `unknown`.
- Default stale interval is 24 hours.
- The host never executes plugin-provided update commands.
- Tests must not depend on live network APIs.

## Review Focus

- Malformed or incomplete plugin JSON must be rejected and preserve the previous cache.
- Plugin stderr must not contaminate stdout protocol parsing.
- Expired/corrupt cache must not crash shell startup.
- Concurrent refreshes must collapse to one process-wide refresh.
- Shell quoting must preserve spaces, quotes, dollar signs, and empty arguments.

### Tasks

1. Add protocol and semantic-version tests, then implement strict JSON validation and comparison helpers.
2. Add cache, lock, subprocess, stderr, exit-failure, and timeout tests, then implement atomic persistence and bounded execution.
3. Add discovery, rendering, command, and concurrency tests, then implement `shell`, `refresh`, `list`, and `doctor`.
4. Add built-in executable plugins, shell integration, authoring docs, and full verification.
